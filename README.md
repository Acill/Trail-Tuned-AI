# TrailTuned AI 🚴‍♂️🤖

TrailTuned AI is a precision mountain bike setup, suspension tuning, and trail advisory web application powered by Gemini AI. It allows riders to input their exact bike components, gear weight, and target trail location to instantly generate professional-grade mechanical setups and advice.

## ✨ Key Features

* **Bike & Gear Profile Management:** Enter detailed component specs including your front fork, rear shock, tires/wheels, brakes, drivetrain, and total rider weight in full gear (supports lbs and kg).
* **Quick Presets:** Instant loading presets for high-end builds like the *2027 Intense Tazer e-MTB*, *Specialized Kenevo SL*, *Trek Fuel EX 9.8*, and *Intense Tracer*.
* **Gemini AI Ride Tuning:** Powered by Google's Gemini AI to analyze trail terrain worldwide and calculate custom suspension air pressures, clicker settings (rebound/compression), and tire PSI.
* **Trailside AI Mechanic Chat:** An interactive chat assistant built right into the dashboard to answer on-the-fly tuning and maintenance questions.
* **Progressive Web App (PWA):** Fully installable on iOS, Android, Windows, and macOS as a standalone app with offline asset caching and local storage persistence.

## 🔑 Setting Up Your Free Gemini API Key

TrailTuned AI connects securely to Google's Gemini API directly from your browser. 
1. Get a free API key instantly at [aistudio.google.com/apikey](https://aistudio.google.com/apikey).
2. Open the deployed TrailTuned AI app in your browser.
3. Click the **"Set Gemini Key"** button in the top right, paste your key, and save. 

*(Your API key is stored securely in your browser's local storage and is never shared or stored on external servers).*
